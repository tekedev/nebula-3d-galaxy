# Nebula 3D Galaxy — Three.js WebGL Simulation

> **Creative Coding Project by Enes Teke (tekedev)**

---

## 🏛️ Executive Summary

**Nebula 3D Galaxy** is an interactive 3D WebGL simulation rendering hundreds of thousands of animated stars, cosmic dust particles, and dynamic galaxy spiral arms using Three.js and custom GLSL shaders.

---

## ⚡ Key Features

- **Particle Engine:** Renders 100,000+ interactive particles with 60fps GPU performance.
- **Interactive Orbit Controls:** Smooth mouse drag, zoom, and perspective rotation.
- **Custom Shaders:** Color gradients and space noise animation.

---

## 🛠️ Tech Stack

- **Core:** JavaScript, Three.js, GLSL Vertex/Fragment Shaders, HTML5 Canvas
